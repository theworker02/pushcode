# pushcode

Push CSV/TSV code tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/pushcode/

## Install / run

```bash
git clone https://github.com/theworker02/pushcode.git
cd pushcode
node src/cli.js
node --test
```
